## 📖 About

This repository contains my complete journey of learning **System Design** from scratch.

The goal is to understand how modern systems are designed to handle:

- Millions of users
- Massive amounts of data
- High availability
- Fault tolerance
- Low latency
- Global scale

Instead of memorizing interview answers, this repository focuses on understanding the engineering principles used by companies like Google, Netflix, Uber, Amazon, Meta, and others.
